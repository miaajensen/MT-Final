# MT-Final: Student-Athlete Planner

## Project Overview

The Student-Athlete Planner is a web application designed to help high school and college student-athletes balance their academic responsibilities with their athletic commitments. Student-athletes often have demanding schedules filled with classes, assignments, exams, practices, games, and competitions. Managing both school and sports can become overwhelming, especially when there is limited time for personal responsibilities and healthy habits.

This application provides a centralized and visually appealing platform where student-athletes can organize their schedules, track assignments, set personal goals, and monitor their academic and athletic progress.

The goal is to make time management easier, encourage productivity, and help student-athletes develop healthy habits that support success both in the classroom and in their sport.

## Target Audience

- High school student-athletes
- College student-athletes
- Students balancing demanding academic and athletic schedules

## Project Goals

- Simplify time management for student-athletes.
- Keep academic and athletic schedules organized in one place.
- Encourage students to complete assignments and prepare for exams on time.
- Motivate users through academic and athletic goal tracking.
- Create a rewarding environment that recognizes achievements.
- Promote healthy habits and a balanced student-athlete lifestyle.

## Key Features

### 1. Academic and Athletic Scheduling
- Create and manage academic events, including assignments, tests, projects, and reading deadlines.
- Add athletic events, including practices, workouts, games, and competitions.
- View academic and athletic responsibilities in one organized calendar.
- Receive reminders for upcoming deadlines and events.
- View countdowns to important events, such as exams and game days.

### 2. Goals and Achievement Tracking
- Set academic goals, such as improving GPA or completing assignments on time.
- Set athletic goals, such as improving personal records or reaching performance milestones.
- Track progress using progress bars and completion percentages.
- Earn points, badges, or rewards for completing tasks and reaching milestones.
- Review previous accomplishments and progress.

### 3. Personalized Dashboard and Productivity
- View upcoming academic and athletic responsibilities.
- Access an organized daily to-do list.
- Mark assignments and tasks as completed.
- Customize the dashboard and calendar.
- Track healthy habits, such as hydration, sleep, and taking breaks.

## Project Epics and User Stories

### Epic 1: Academic and Athletic Scheduling
Focuses on helping student-athletes organize their academic and athletic responsibilities.

- As a student-athlete, I want to add assignments, tests, and reading deadlines to my calendar so that I can keep track of my academic responsibilities.
- As a student-athlete, I want to add practices, games, workouts, and competitions to my calendar so that I can organize my athletic schedule.
- As a student-athlete, I want to view my academic and athletic schedules together so that I can see how my responsibilities overlap.
- As a student-athlete, I want to receive reminders about upcoming assignments, tests, and athletic events so that I do not forget important responsibilities.
- As a student-athlete, I want to see countdowns to important events so that I can prepare ahead of time.

### Epic 2: Goals, Progress, and Achievement Tracking
Focuses on motivating student-athletes to improve academically and athletically.

- As a student-athlete, I want to create academic goals so that I can track my progress in school.
- As a student-athlete, I want to create athletic goals so that I can monitor my development as an athlete.
- As a student-athlete, I want to view progress bars or percentages so that I can see how close I am to achieving my goals.
- As a student-athlete, I want to earn points, badges, or rewards so that I stay motivated.
- As a student-athlete, I want to view my past achievements so that I can reflect on my improvements.

### Epic 3: Personalized Dashboard and Productivity
Focuses on providing a centralized space for managing daily responsibilities and developing healthy habits.

- As a student-athlete, I want to see my upcoming responsibilities on my dashboard so that I know what I need to accomplish.
- As a student-athlete, I want to view my responsibilities in a to-do list so that I can prioritize tasks.
- As a student-athlete, I want to mark assignments and tasks as completed so that I can track what I have accomplished.
- As a student-athlete, I want to customize my dashboard and calendar so that I can organize information in a way that works best for me.
- As a student-athlete, I want to track healthy habits so that I can maintain a healthy balance between academics and athletics.

| React | Frontend development and user interface |

## Planned Development Stages

1. **Project Setup:** Create the project repository, establish the frontend and backend structure, and configure the development environment.
2. **Frontend Development:** Build the React interface, navigation, dashboard, calendar, and to-do list.
3. **Backend Development:** Develop the backend functionality for managing users, events, assignments, and goals.
4. **Database Integration:** Create a database to store user information, schedules, assignments, goals, and achievements.
5. **Feature Implementation:** Add reminders, countdowns, progress tracking, rewards, and healthy habit tracking.
6. **Testing:** Test application functionality, fix bugs, and improve usability.
7. **Containerization and Deployment:** Use Docker to containerize the application and deploy it through Google Cloud Platform.
